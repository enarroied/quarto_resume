## Selected Geospatial & Data Projects

**2026 – Present | France Geospatial Lakehouse**

Personal project building a modern data platform for French municipalities, combining geospatial and statistical open data.

- Designing **Bronze / Silver / Gold** data layers with **GeoParquet, Apache Iceberg and DuckDB Spatial**.
- Spatial data processing with **Python, GeoPandas and PostGIS**.
- Building reproducible pipelines for downstream GIS and analytical applications.

**Sentinel-2 Urban Vegetation Analytics**

End-to-end geospatial analytics application developed as part of *Getting Started with Taipy*.

- Computed **NDVI time series** from **Sentinel-2 imagery via OpenEO** over Paris parks.
- Built an interactive Taipy application to select parks and compare vegetation profiles.
- Demonstrated the integration of remote sensing, spatial data and interactive analytics in Python.

**QGIS & Field Data Workflows**

Geospatial workflows developed during my work in viticulture, including:

- Development of a **QGIS plugin in Python** for vineyard management.
- Extraction of cadastral information from documents, matched to cadastral polygon datasets.
- Field data collection workflows using **QField**, with processing and visualization in QGIS.
- Automated generation of maps and analytical reports.
